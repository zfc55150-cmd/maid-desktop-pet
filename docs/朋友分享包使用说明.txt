蓝鲸女仆桌宠 1.2.1 · Windows 64 位朋友分享包

一、安装与开始
1. 将整个 ZIP 解压到本地文件夹，不能直接在压缩包里双击安装。
2. 双击“安装桌宠.cmd”。无需管理员权限；安装会复制并校验文件，可能需要几分钟。
3. 完成后打开桌面“DeepSeek 蓝鲸女仆”快捷方式。
4. 右键人物 → 设置与聊天记录，填写你自己的 DeepSeek API Key 并保存，然后开始对话。
5. 退出：使用桌宠右键菜单；也可以打开安装目录中的 stop.vbs。

二、电脑和空间
适用于 Windows 10/11 x64；其他系统和 ARM 设备未验证。
包内自带 Node、Electron、Python、动画和本地语音模型，不必预装开发环境。
建议安装时保留至少 40 GB 空闲空间，用于 ZIP、解压文件和安装副本。
聊天需要联网，并由你自己的 DeepSeek 账户承担 API 费用。
默认关闭语音。开启本地语音需要兼容的 NVIDIA 显卡、驱动及足够显存，具体性能取决于电脑。
未在朋友的电脑上验证显卡与语音兼容性；不使用语音也能进行文字聊天。

三、数据与费用
分享包不包含制作者的聊天记录、长期记忆、个人设置、API Key 或控制令牌。
第一次安装使用通用人设和空记录；所有 Key 均由接收者自己填写。
聊天、人设和长期记忆会按功能需要发送给 DeepSeek；语音模型在本地运行。
自动长期记忆默认开启，会产生额外的 DeepSeek 请求和费用，也可能记错。
你可以在设置里查看、纠正、删除记忆或关闭自动整理；关闭后已有记忆仍会用于聊天，可另行删除。
设置里的清空功能只清理所选择的本地记录，不会撤回已发往服务商的请求。

四、安装位置与维护
程序：%LOCALAPPDATA%\Programs\DeepSeekActionPet
个人数据：%LOCALAPPDATA%\DeepSeekActionPet
安装脚本拒绝覆盖已有程序目录，也不会覆盖已有个人数据；遇到已有版本时请先联系维护者。
卸载时先退出程序，再删除程序目录和快捷方式；个人数据独立保留，可按需自行备份或删除。
本分享包包含 DeepSeek 桌宠；不含另一款 GPT 娘及其集成补丁。
原项目、依赖和语音模型的说明及许可随程序保留，以各组件自带许可为准。

五、校验和验收范围
“分享包校验.json”记录 ZIP 的 SHA-256；可与收到的文件核对是否传输完整。
program/recovery-manifest.json 记录每个程序文件的 SHA-256；安装前后均逐文件核对。
在解压目录执行 powershell.exe -NoProfile -File .\install-share.ps1 -VerifyOnly 可只校验、不安装。
本次验证源码与已安装的 46 个部署文件一致，59 项假数据回归通过，ZIP 程序文件逐项校验。
没有调用真实聊天接口，也没有在另一台实体电脑上完成安装或语音验收。
