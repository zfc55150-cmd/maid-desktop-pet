# GPT娘制作：本地模型与API的实际取舍

核对日期：2026-10-23。本结论只针对现有机器、模型和已保存试片，不是所有本地模型与所有API的通用排名，也不是相同提示词、种子和分辨率的严格横评。

最新限制：用户报告视频模型费用不能由其300元代金券抵扣，账户已欠费。本项目已停止所有新增付费视频、图像和文字调用，并在提交入口增加本地拦截。现阶段只继续已下载素材的本地后期与验收。下文的API主线是技术质量比较，不表示现在仍允许付费生成。Token Plan专属入口误配导致按量扣费是一项待查可能性，不能据此断言用户套餐支持wan3或直接改接口试调用；需核对订单与明细。

本地原始尝试曾在VAE拼接阶段显存不足；现有wan_decode_cpu.py把拼接移至CPU，真实GPU对照最大差0，后续193帧成功。它修复的是可运行性，没有修复上述美术缺陷。8GiB显存下现有路线是经过卸载和拼接调整才跑通，不应将官方4090示例速度直接套用到本机。

现阶段主线采用API生成、主助手逐帧检查并在本机修边与验证。本地模型保留，不删除、不重新下载；除非有针对质量问题的具体新方案，不盲目重复昂贵的本机长任务。动作质量不能靠插帧、加倍时长、放大输出或透明编码成功来证明。

费用按官方公开原价保守预留：720P为0.6元/秒，三秒约1.8元；480P为0.3元/秒。预留不等于账单实扣或优惠券抵扣。保存的单次2元限制和月/累计预算未更改。
