# GPT 娘屏幕边缘点击和拖动卡死修复

2026-11-09，本机 GPT 娘更新到 `0.8.23-electron`。旧版连续两次在甩动时停止更新心跳，透明窗口停在鼠标穿透状态。现场主线程调用栈停在 Windows 错误框，错误参数指向 `desktop-geometry.cjs` 的 `setPosition`。用相同 Electron 二进制复现了两个轴上的转换错误。JavaScript 将靠近零的负数取整成负零时，Electron 会拒绝这个窗口坐标。

新版在人物移动、启动时定位以及摆放气泡、提示和菜单时统一转换窗口坐标，保留真正的负坐标。主进程的意外异常会记录固定错误码和本地代码位置，再退出，由正式版监督器接回启动。这样可以避免 Electron 的模态错误框把窗口和输入一起锁住。

105 项单测、272 项隔离 Electron 回归以及 3 项退出和再启动验证通过。实际 Windows 鼠标验证覆盖单屏中央与四边区域，每处都能点按并按目标位移拖动。另有模拟负坐标和跨屏碰撞用例，本轮没有混合 DPI 的双屏实测。正式包通过 289 个文件校验，激活前核对了四项已有个人配置的哈希，正式进程重新显示并恢复心跳。启动入口仍是「打开GPT娘」。

本机更新交付与回退记录在 `work/gpt-input-origin-fix-20261109-02`。基线为 `0.8.22-electron`，旧版本目录和 `root-backup` 保留。已有的 GitHub 便携附件仍是发布时的历史包。
