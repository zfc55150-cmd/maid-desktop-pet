# 双桌宠审计与发布状态 · 2026-11-12

当前公开下载为 [v1.0.1](https://github.com/zfc55150-cmd/maid-desktop-pet/releases/tag/v1.0.1)。DeepSeek 旧包在全新解压后可能无法显示桌宠，且 Electron 配置可能写到用户目录。新候选已通过 Windows 首启、包内配置、假 Key 加密保存和独立停止验证。

本次 GitHub 源码更新带来双宠更新提醒修复、发布标签校验、素材许可检查、隐私清理及 GPT 主进程异常诊断。正式便携版仍需完成许可核对和双包验收。
