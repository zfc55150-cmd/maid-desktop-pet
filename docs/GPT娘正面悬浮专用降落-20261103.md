## 素材与播放

- 输入为正式 `frontpose` 第 179 帧与 `frontidle` 第 0 帧；画布位置保持一致。
- 单次 `wan3.0-video` 请求，3 秒、30 fps，实际原片 1440×1440、90 帧。没有自动重试，也没有更改预算或切换服务商。费用保守预留 3.6 元，未核对平台账单。
- 新增 `frontlanding`：全程正面，小幅下降、屈膝缓冲、站稳收势。90 帧脸部及全身抽样、单尾、闭嘴、透明边缘和首尾衔接已作技术审查。

- 正面动作链为 `frontpose → frontlanding → frontidle`，降落按原速播放，完整单次表演 9 秒。手动点播和自动待机共用这条链。
- 拖拽飞行仍为 `flutter → draglanding → frontidle`，起飞速度渐变、悬停保留、惯性阶段与松手落地逻辑保持原有行为。新降落只作连接动作，不加入自动随机池。
