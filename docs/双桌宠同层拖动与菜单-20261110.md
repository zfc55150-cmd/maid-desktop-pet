# 双桌宠同层拖动与菜单

本机更新到 GPT 娘 `0.8.25-electron`（基线 `0.8.24-electron`）与 DeepSeek `1.2.3-window-menu.1`（基线 `1.2.3-chat-setup.1`）。两只桌宠置顶时使用相同的窗口级别。DeepSeek 开始交互时显式把自己的窗口提到前面，GPT 娘继续在抓取时提到前面；两者空闲时不反复争抢前后顺序。用户已有的 GPT 娘置顶开关仍可关闭置顶。

GPT 娘右键「重载配置」走正常退出收尾，本机监督器重启并从磁盘读取设置，不写用户退出的暂停标记。DeepSeek 右键「退出」只通过本机已认证的控制接口停止 DeepSeek 宿主；回复或朗读中拒绝退出，不会影响 GPT 娘。

验证：真实 Win32 的两个透明测试窗口交替提到前面，等待超过旧置顶检查周期后保持顺序。DeepSeek 144 项回归及 51 项安装文件校验通过。GPT 娘 106 项单测、125 项隔离 Electron 回归通过，隔离菜单以 `reload` 正常退出；正式包 293 项校验通过并恢复可见。两套安装前的个人文件哈希均通过核对。

代码更新包与回退材料：`work/gpt-layer-reload-20261110-01` 与 `work/deepseek-window-menu-20261110-01`。前者使用该目录的 `install-release.cjs <stage> --rollback` 流程；后者使用 `scripts/rollback.ps1` 与对应「更新前代码」备份。两套包均不包含模型、聊天记录或凭据。
