# GPT娘拖动与甩出后瞬移修复

基线为 `0.8.8-electron.1`，修复版为 `0.8.9-electron`。用户明确反馈：拖动或甩出之后，人物有时突然跳回别处。本轮维护入口是 `integrations/gpt-niang/product-electron/`。

## 原因与复现

当前个人设置启用了跟随 Codex 窗口。正常松手会保存新的相对偏移，但取消、失焦、漏收松手后的看门狗恢复，以及飞行中断，原先只清除交互状态，没有保存人物已经移动到的新位置。下一次恢复原生跟随时，旧偏移重新生效，人物便跳回旧位置。

回归直接执行生产 `main.cjs` 的窗口写入、位置保存函数和 Motion 事件回调：窗口从 `(400,300)` 拖到 `(620,220)`，中断后恢复跟随，旧版会回到 `(400,300)`。这不是依据测试数量推断出的原因，而是可重复的位置结果。

另有两处交接缺口：物理停稳事件先保存窗口位置，调用方随后才写入最终物理坐标；移动去重只比较上次请求坐标，不能察觉原生跟随已经移动过窗口。这两项也已修正。

## 实际改动

- 取消交互时携带取消前的运动阶段；只在拖动或飞行被中断时保存当前真实窗口位置，普通空闲恢复不改锚点。
- 停稳事件携带最终物理位置，先写到窗口，再保存跟随偏移和处理落地。
- 对重复位置请求额外核对窗口实际坐标，防止原生跟随移动后错误跳过必要的位置写入。
- 隔离测试也保存位置，但只写 `ProductHost` 分配的假数据目录，正式个人设置不进入测试。

保留跟随开关、人物大小、置顶、角色和素材，沿用重力、甩出速度、碰撞、起飞及降落规则。新版本不改变原生宿主选择策略；主动移动 Codex 窗口时人物仍按原有设置跟随。中断后的当前位置现在会作为后续跟随偏移保存，这是本次修复的预期行为。
