# 预览入口故障与修复

2026-11-02，用户反馈无法预览，随后明确允许“现在临时切换并完成验证”。仅修复隔离实验工具，未部署GPT架构替换或修改DeepSeek共享代码。

## 已定位的故障

首个会话`session-1793555757613`中，候选确已取得正式命名互斥量并显示，但旧PowerShell进程没有在8秒内完全退出。控制器只等待PID消失，将交接误判为失败，关闭候选并恢复正式挂件。因此当时的“已安排预览”不等于可用性已验证。

另外，直接在Chrome中打开`review-video.html`无法连接Electron预加载接口，旧页面缺少明确提示。浏览器页与独立播放器不是同一入口。

## 修复

- 保留PID退出判断；同时接受受校验的新显示权凭据。凭据必须匹配候选PID、正式互斥量键哈希、当前请求时间、可见状态和持锁状态，并核对对应进程确为本候选Electron。旧进程可继续收尾，不强杀正式进程。
- 修复后会话`session-1793582859458`返回`displayOwnershipReleased=true / processExited=false / cleanupPending=true`，控制器保持在`preview`，不再关闭已成功显示的候选。
- 交接判据通过6项回归检查：新鲜有效凭据可接受，错误PID、未显示、未持锁、错误键及旧时间均拒绝。
- 失败后恢复单独记录为`restored-after-failure`，避免单看“恢复成功”掩盖预览失败。
- 浏览器直接打开页面时显示正确启动提示；独立入口新增`打开GPT娘预览.cmd`。动作加载失败会显示错误，而非继续假报成功。控制台会明确显示等待、取消、打开与恢复状态。
- 默认仍等待空闲；本次现场验证使用用户明确批准的一次临时显示切换，仅允许忽略Codex观察状态，不忽略实际拖动、音乐、配置音效或交互面板保护。
