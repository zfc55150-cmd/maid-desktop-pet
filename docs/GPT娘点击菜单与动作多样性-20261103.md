# GPT娘0.8.6：点击、菜单与动作多样性

本轮以0.8.5-electron为基线，只更新GPT娘产品宿主及调度；不改DeepSeek应用，不替换角色素材，不调整个人尺寸、位置、语音与密钥。0.8.5允许用户点击时激活窗口的修复继续保留。

## 使用

- 点击人物：第一次显示额度，同时刷新本地额度状态；此后显示语录。连续60秒没有点击人物或语录卡片，下一次点击重新显示额度。拖动、取消按压和右键菜单不计入点击序列。
- 点击语录卡片：换下一条。自动语录不消耗首次点击；应用重新启动也从额度开始。
- 右键：直接“切换形态”（全身/半身）、“调整大小”；第二组是动作点播、陪伴模式、音乐律动、安静30分钟；最后是更多设置、退出。静默期间可用“恢复自动陪伴”。
- 陪伴模式：活泼、自然、安静。沿用已有设置，默认自然。置顶、跟随、语录管理和形象图库仍在“更多设置”中，右键不再堆叠这些子菜单。

半身是现有静态形态，全身动画开启时才播放43段人物视频；没有把全身视频强行套到半身上。

## 重复动作的原因与处理

现有43段/7500帧素材不等于43段都适合随机待机。原自动池14项；工作/思考分支主要重复思考和环顾，并且两个任务阶段来回变化会频繁重新请求思考。

现在自动池20项，新增侧身放松、轻松换重心、回应、思考、困倦、疑惑。选择优先照顾较久没有真正显示的动作，避免刚播完就重复；冷却从实际显示开始计数。工作和思考视为同一调度阶段，自然模式能穿插7种不同表现；已经开始的自然动作会完成原有返回路线。手动点播、拖动/飞行和真正的任务状态变化保留优先级。媒体失败的自动选择冷却60秒，避免同一失败项连续霸占选择。

B姿态动作通过原有C→B、动作、B→C完整路线呈现，不硬切。A姿态的三个动作因缺少进入桥段暂时仍只供手动使用。并未将拖动、落地或持道具的特殊片段不加区分地随机播放。

20分钟确定性时间模拟中，实际目标帧覆盖：待机14→20种，频繁工作/思考切换2→7种，请求数1200→70。模拟使用真实目录、播放计划与目标呈现事件，不能代替真实桌面原速、长期观感和多屏DPI验收。
