# GPT娘气泡对齐DeepSeek与悬停名称恢复

用户反馈小形态文字卡片离人物太远、卡片样式不满意，并要求大、小形态直接采用DeepSeek的气泡，恢复鼠标悬停时的人物名称。

本轮从正式 `0.8.9-electron` 独立更新为 `0.8.10-electron.1`。原有43段/7500帧、角色、大小、位置、置顶与跟随设置保留。

## 原因与改动

旧卡片按方形透明窗口顶部定位；小形态实际只占底部，透明留白因此变成了很大的卡片间距。现在小形态以原图片的透明蒙版定位头顶；全身以既有待机轮廓定位。卡片随形态、人物大小、窗口位置与屏幕工作区更新，边缘限制仍生效。

`app/deepseek-bubbles.css` 逐字复制当前维护的DeepSeek `app/electron-helper/index.html` 气泡规则，包括字体、字号比例、半透明白底、圆角、阴影、三角尾巴、碎碎念换行和宽度限制。单独原生窗口仅调整容器定位与阴影留白；使用480像素CSS参考值和现有文字大小/DPI设置缩放。去掉“陪你一会儿”标题、工具栏、关闭按钮和额度进度条，短句窄框、长句自动换行。额度仍显示百分比和重置时间，点击仍切换本地语录，气泡沿用原有自动收起时间；设置从人物右键进入。

Electron版虽保留了角色名字和命中检测，却漏接了悬停名称的渲染。现在复用随包已有的DeepSeek `TOOLTIP_CSS`、`tooltipPlacement` 和软糖字体，在光标附近显示“ChatGPT 傲娇龙娘”；自定义角色使用实际角色名。两种形态都按不透明人物命中显示，透明区、拖动、飞行和菜单期间隐藏。名称窗口不接收鼠标、不激活窗口，不改变人物输入窗口的可激活设置。

## 验证

83项本地回归通过，包含原样CSS核对、不同形态/大小/负坐标工作区的定位和悬停门控。候选及正式安装各21项真实Electron检查通过，且均正常零码退出，覆盖两种形态的样式、字体、间距、名称、透明命中、拖动隐藏、短长文本宽度、缩放以及额度点击。

当前144 DPI环境、413像素画布、文字大小1.2的隔离测试中，小形态尾巴与可见人物顶部间距约12像素；缩到289像素画布后仍约11像素。候选和安装截图均已渲染并复核。截图是隔离窗口的实际渲染结果按真实坐标组合，不能替代用户真实鼠标长期体验。

第一次几何检查因多次像素取整累计约2.1像素，超出2像素测试误差而失败；保留原始失败报告和现场，按可解释的3像素取整范围复核。没有用更大定位空隙掩盖问题。
