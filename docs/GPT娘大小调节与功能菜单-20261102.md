# GPT 娘大小调节与功能菜单

本轮版本：`0.8.2-electron`，基线为 `0.8.1-electron`。用户反馈上一版人物过大，而右键功能菜单偏小，要求参考 DeepSeek 增加独立的大小设置窗口。

## 使用

右键人物 → **调整大小**。滑块可选 45%–175%，提供默认 100% 和“保存并应用”。保存立即调整人物，无需重新加载；保存后下次启动沿用。此窗口也会在本轮交付时打开。

人物标准身体高度由上一版 480 调为 360 像素。现有 `scale=1.2` 不变，画布由 472 变为 354 像素；沿用脚底位置与水平中心，屏幕边缘会作边界限制。100% 对应原设置 `scale=1.4`，独立窗口中以百分比呈现。

右键功能菜单改为独立窗口绘制，参考 DeepSeek 的 13px 字号、30px 行高、150px 最小列宽、圆角和悬停样式，按显示 DPI 缩放。人物大小、菜单大小和文字卡片大小分开计算；当前 150% 缩放下菜单最小宽度为 225 个物理像素，避免上一版约 136 像素的小菜单。新增直接的“调整大小”入口，保留额度、语录、43 项动作、形态、陪伴、跟随、置顶和退出。

支持级联、勾选状态、鼠标外点关闭、Escape 关闭、方向键和屏幕边缘定位；长列可滚动。菜单预加载单独限制 IPC 调用者，执行函数只保留在主进程，网页无法传入任意命令。
