# 人物锁定与制作规范

## 三张参考图各自做什么

|文件|用途|不能怎么用|
|---|---|---|
|01_C姿态主锚点_原始绿底.png|脸、线条、颜色、已有头身与长裙比例，默认起末姿|不能再压扁、加大头、缩短腿、改成更幼态圆团；也不擅自拉成长成人比例|
|02_正侧背结构参考.png|转身时的翼根、背面、长发与服装结构|不能把三个人放进视频；不能拿整张三视图当首帧|
|03_单尾结构说明.png|唯一尾根、白鳞厚根、向内卷、渐细且唯一尾尖|不能把分栏和文字生成进视频；不能把尾尖变成第二个头或分叉|

主锚点原始782×1176像素，保留原字节。脸、比例与色调有差异时以主锚点为准，三视图补侧背结构。发饰在角色自身左侧，即正面画面右侧；尾卷通常在自身右侧，即正面画面左侧。禁止整片镜像偷换左右。

**C是项目既有“正面放松站姿”的姿态编号**，不是画面中心坐标、旋转角度或新角色。本文“回C相容”指回到参考图相容的全身站姿、手位、脚底与尺度；不要求逐像素复制静帧，也不允许硬切回参考图。

白发、紫眼、分节白角、尖耳、弯曲呆毛、白紫长裙、露肩垂袖、结饰流苏、原鞋、两只小膜翼、唯一白鳞卷尾保持。保持长裙的纵向身体线条、现有比例和原有半身形态。主锚点中被遮住的小翼参考侧背图，不为“飞得壮观”突然增大成巨翼。

全程保留无声闭口表演：闭口嘴线可以轻压、上扬、左右不对称；不用张嘴、台词、字幕或音效替代表情。情绪顺序是眼神/眉先变，头肩跟进，手和重心完成反应。不要一直半眼冷脸，也不要一直甜笑。

## 动作空间与小尺寸可读性

- 所有六条默认**固定镜头、一个连续场景、完整人物**；不推拉、摇镜、切近景、景深糊脸、转镜头或慢动作。镜面倒影是P04明确规定的局部画中对象，不能变成全身第二人。
- 以静止角色可见高度 H 定义尺度。一般道具主形至少约0.15H；脸、手和物体留分离。不要靠缩小全身给巨特效让位。
- P02等需要留白：建立独立宽画布派生参考，原人物只作一次等比缩放和平移；整段同一变换。根据真实轨迹预演留边，不能每帧自动缩放、自动居中或只让人物变小。保留原参考、派生图、画布与变换记录。
- 建议工作画布至少1440×1440、静止人物有效高度约1000像素，或与源入口实际支持相当且足够的规格。**这是制作目标，不是已核实API参数，也不是把原锚点放大就获得新细节。** 原生源受限时保留真实规格，先看有效细节；后期放大单独标注。
- 成品除高分辨率母版，再提供人物可见高度约300px的同速预览，另在当前正式桌宠用户大小下由主助手复核。道具、尾翼动作和转折在小图里仍要能读清。300px只是对照尺寸，不宣称用户当前恰好设为300px。
- 背景不出现桌面截图、真实窗口、文字、地板、投影板或室内场景。除P04独立镜面、P03机关龙等指定内容，不新增演员。

## 运动与接触

- 站立有支撑脚，动作由重心和躯干发起；手臂不是粘在肩上独立摆动。P02明确允许腾空，其他片不整个人漂移。
- 发根随头，发梢迟到、越过后回弹；袖口随腕后摆，裙片随髋部受力，流苏有不同延迟。不能给所有层同一个正弦波。
- 小翼是身体结构，翼根固定、关节转向可追踪；尾巴从原尾根连续伸出。允许生理合理的松卷/摆动，保留厚根到细尖与收卷特征，不像绳子无限拉长、不新增关节、不穿裙。
- 手、道具和尾巴的接触要在预演里标注。尾巴能托/挡，不代替长手指捏精密零件；小动作不能靠伸长尾尖实现。
- 主事件连续，不能用人物淡出、突变、重复帧、倒放或长交叉淡化掩盖关键步骤。

## 画面与透明路线

原设白发白裙保留；用灰紫遮挡、发束前后关系、手背与袖口分离、局部暖金/深紫道具提高层次。禁改深色新服装，禁过曝纯白抹掉细节。P01纸张用浅暖纸色且有清晰深紫边；P05瓷饰用深紫灰而非另一个白团。

生成入口有真正alpha能力时可交透明源，但必须检查真实alpha通道，黑底不算透明。否则使用干净均匀的纯色背景。当前主锚点是绿底；可用与它一致的纯绿路线，避免绿色前景与反射染色。P04镜面和P06液体不适合用一次绿幕抠像硬做完整透明；优先独立人物、道具、反射/液滴与少量光效层，保留遮挡顺序。

发光有可见实体轮廓，光晕只作次级信息。要有分别可关闭的光效/辉光层；不能把大雾、全屏闪白或耀斑当作“高级”。在浅灰、近黑和高饱和背景上检查原速，特别看白发、手指间隙、尾翼边和液滴。处理溢色不能把白发削薄。

最终母版优先无损RGBA序列或带alpha的高质量中间格式，另保留未抠原片。源时序目标原生30fps；原生24/其他规格如实登记，以原速检查，不能靠复制帧/插帧改成“原生30/60”。不强行适配旧384图集或旧WPF状态限制；当前产品是Electron，具体接入由主助手另做。

静帧与PNG序列以sRGB观感为目标；视频记录实际色彩原色、传递函数、矩阵与范围（可得时），合成预览按正确的sRGB/Rec.709显示转换检查。不要无标记混入P3/HDR导致白发与紫色偏色。源色彩元数据缺失时写“未标记”，不编造检测结果。无声成品可以无音轨；若源入口强制产音频，原片保留、预览/母版明确静音，无需伪填音频采样率。

## 起末姿和分层生产

默认前0.5秒进入准备，最后1.5—2秒完整收势，末0.5秒稳定在C相容姿态。对齐的是人物尺度、脚底与身体中心，不能把首末姿严格约束变成中段僵站。六条均为一次性表演，不能冒称无缝循环。

多段生成必须沿同一连续镜头和同一人物空间衔接，保留段边界、每段参考帧和合成清单；不能用跳切让观众看不到动作。难题可通过先做关键姿态/动作预演、再生成和精修解决，不能凭文字声称“逐帧修过”。
