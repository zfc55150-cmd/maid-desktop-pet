# GPT娘补充动作任务书（交给 Gemini 3.8 Flash）

当前43段素材的主要问题是调度重复，0.8.6已先改善；这份任务书用于下一批补充，不是当前版本的安装前提。建议先做01、02各一条，通过首尾衔接验收后再批量制作。

## 可直接复制的总要求

请按附件中已经认可的GPT娘参考图制作桌宠动作视频，每条独立交付。参考图决定角色的脸、发型、角、尾巴、衣服、配色和身体比例；保留龙娘、长裙和原有角色气质，不额外Q版化、压扁身体或改成另一位角色。现有半身形态不需要重做。

固定镜头、固定人物大小、固定站立位置，完整身体与尾巴不裁边，四周保留与参考图相同的透明留白。没有镜头推拉、摇晃、切镜、背景物体、字幕、水印、新道具或说话口型。不是把一张静态图整体摇摆：动作应由眼、耳、肩、手等相关部位自然完成，头发、裙摆、尾巴有小幅滞后与收势；呼吸持续自然，不要求身体僵直。

建议原始画布1024×1024、原生30fps、单条6—8秒，优先保留最高质量原片。若生成工具支持真正透明通道，可交透明版本；否则交干净、均匀、与人物颜色有明显区别的纯色背景原片，后续单独检查抠像，不把黑底视频冒充透明视频。不要通过复制帧、插帧或强运动模糊伪造30fps。

下面01—08全部是C姿态动作：用随包的 `C姿态参考_frontidle.png` 作为姿态基准。开头约0.8秒自然站稳，中间完成一次动作，最后约1秒自然回到同一站姿。首尾人物的脚底、身体中心、头部大小和手的位置要对齐；表情平顺回归，避免最后一帧突然跳回。这里的“C”只是项目姿态编号，不能自行理解成旋转角度。

## 第一批：自然待机微动作

| 编号与文件名 | 中段动作 | 要避免的问题 |
|---|---|---|
| 01 `c_soft_breath_blink` | 安静呼吸，眼睛自然眨两次，肩膀与发梢极小起伏，再平静看向用户 | 全身上下浮动、胸口夸张起伏、眨眼频率机械一致 |
| 02 `c_listen_ear` | 一侧耳朵轻动，眼神转向声音方向，头轻偏，像认真听了一下，再看回用户 | 头转到侧脸、角变形、耳朵忽然增减 |
| 03 `c_tail_tip_settle` | 尾尖在原有轮廓附近缓缓轻摆一次，身体轻微配合，收回原位 | 尾巴扫出画布、穿过裙子或变成另一条尾巴 |
| 04 `c_brush_fringe` | 一只手轻拢额边发丝，略带小得意，手自然落回参考位置 | 挡住整张脸、手指增减、手快速瞬移放下 |
| 05 `c_hands_rest` | 双手在腰前自然靠近、松松相合，停顿片刻后放回原位 | 手掌交叉穿模、新增饰品、肩膀僵住 |
| 06 `c_small_weight_settle` | 重心轻轻换到另一只脚，裙摆有小幅自然跟随，最后回正 | 走出原地、脚底滑动、人物整体缩放或左右漂移 |
| 07 `c_notice_user` | 注意到用户，目光对准镜头，眉眼轻微上扬，短暂柔和微笑，再恢复平静 | 张嘴说话、夸张大笑、表情突然跳切 |
| 08 `c_suppressed_yawn` | 眼睛略困，闭嘴克制地放松一下肩膀，小小眨眼，再恢复精神 | 夸张张口、趴下睡觉、长时间闭眼、伸展出画布 |

每条动作均缓入缓出，不重复整段动作三次来凑时长。动作可辨认，但强度以长时间桌面陪伴为准。

## 第二批：优先补齐姿态连接（需另附两端原图后制作）

现有自动路线已能安全使用C和B动作；A姿态的三个动作缺少进入连接，暂未硬接进自动池。下面两条的首尾必须取自现有素材，不允许凭文字重新设计姿态。先整理两端参考帧，再生成，不要拿C参考代替A或B。

| 文件名 | 精确输入与要求 | 价值 |
|---|---|---|
| `bridge_b_to_a` | 首帧取当前 `brelaxed` 的稳定B姿态，末帧取当前 `idle` 的稳定A姿态；约3—4秒，在原地自然转身，手、裙与尾巴连续跟随 | 补上B→A入口，后续可接入A姿态的站立、轻摇和重心变化 |
| `bridge_a_to_c` | 首帧取当前 `idle` 的稳定A姿态，末帧使用附件C参考；约3—4秒自然回到C | 缩短A动作回正路线，减少频繁转身的机械感 |

两端姿态均以附件为准，不指定“旋转90度”等未经参考验证的角度。人物大小、位置、脚底与画布必须一致。若无法同时满足首尾，交问题说明和候选，不能用硬切或淡出掩盖。

## 交付与验收

每条交付原始视频、实际分辨率/帧率/时长说明、首尾无损PNG；保留独立文件名，勿混入旧素材。先验01、02，再继续其余动作。我们会按原速检查面部与手部稳定、尾巴穿模、脚底滑动、抠像边缘和首尾衔接，再决定是否接入；技术可播放不等于画面通过。

已有43段素材和本次20种自动池保持可用，不需要为赶数量重做现有动作。没有在本任务中调用生成接口或付费生成视频。
