## 二、第一阶段：Bug 与潜在隐患修复清单

### 1. [高优 Bug] Windows 下 `ChatConfigStore` 原子锁与文件重命名偶发 `EPERM/EACCES` 竞态报错
- **文件**：`app/electron-helper/chat-config-store.js`（第 90–126 行）
- **现象与根因**：
  - 在运行全量回归测试 `tests/auto-memory.test.cjs`（高频连续对话与后台记忆中止用例）时，实测捕获到偶发报错：`Error: 聊天配置未能保存，原文件和备份已保留。请检查磁盘空间及目录权限后重试。`
  - 根因在于 `createLock()` 在临时目录写入并 `fsync` `owner.json` 后立即对该目录执行 `fs.renameSync(temp, lockPath)`，以及 `writeAtomic()` 连续快速替换 `chat.json` 时，Windows NTFS 过滤器 / Defender 会短暂持有新文件句柄数毫秒并抛出 `EPERM`。
- **修复内容**：
  - 新增 `renameRetry(from, to, beforeRename)` 方法，对 Windows 瞬态 `EPERM` / `EACCES` 执行最多 8 次短退避重试（`Atomics.wait`，每次 `5 * (i + 1) ms`），且每次重试前重新执行 `beforeRename()` 乐观锁与锁存在性检查。
- **哈希变更（`deployment.json`）**：
  - `previousSha256`: `34afeeceded32f9efcf876ecb0650591f92c9899ae5e6b4bc971cf6e12f8d3c0`
  - `sha256`: `248c8e1a39352af61978524d36aeee0c45f54a14e92fe8a34ee470870cdc9a1d`

### 2. [观感 Bug] 共享引擎 `sprite.js` 硬编码 `FEET_Y=330` 导致龙娘脚底陷入屏幕/任务栏下方约 21px
