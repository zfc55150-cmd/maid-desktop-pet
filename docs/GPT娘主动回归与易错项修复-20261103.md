# GPT 娘主动回归与易错项修复

正式版本 `0.8.4-electron`，基线 `0.8.3-electron.2`。维护记录在 `work/gpt-electron-proactive-audit-20261102-01`，目录名沿用开始检查的日期。

本轮主动检查发现并修复以下问题：

1. **多窗口保存覆盖大小**：外观窗口原先提交整张表单，既会覆盖独立大小窗口的新值，也可能把精细比例按滑块步长改掉。现在只提交实际修改项，并核对被修改字段的原值。同字段冲突保留输入，提供“重新读取”；不同字段可以合并。
2. **保存冲突后长期不可写、部分保存**：非冲突的外部修改可以合并，冲突不再永久禁用保存；可重新读取修复后的文件。先校验全部设置，跨设置文件写入失败时恢复已经写入的部分；回退前检查文件归属，避免覆盖并发修改。保存期间阻止重复提交和继续修改表单。
3. **已打开的文字卡片不应用设置**：修改文字卡片大小或置顶后立即更新现有卡片，保留原来的文字，按已测量的 CSS 高度重算实际窗口高度。
4. **关闭窗口跟随后重启位置跳回**：关闭跟随时立即解除原生跟随，并保存当前自由放置位置。
5. **语录编辑丢失权重**：使用文字编辑器保存时保留未改动语录的既有权重；新增语录默认权重 1。格式错误的行会被拒绝。
6. **图库选中状态滞后**：选择形象后立即刷新“使用中”，并验证从自定义静态形象返回动画龙娘。
7. **级联菜单键盘进入不完整**：右方向键进入子菜单并聚焦首个可用项目；从未选中状态按上方向键落在末项。
8. **快速重抓的低概率空白帧**：崩溃后新进程压力回归曾复现一个全透明帧。旧视频监视回调现在必须同时拥有当前请求代次，不能在新抓取后撤掉保留画面；新解码表面必须有有效像素后才能释放保留画面，命中状态同时等待真实画面就绪。失败报告保存在 `lifecycle-restart-failure.json`。

## 使用

原有入口保持。右键人物 → **调整大小**；外观窗口和大小窗口新增 **重新读取**。只有发生实际冲突时才需要重新读取，操作不会悄悄覆盖别处刚保存的值。
