# GPT娘0.8.8-electron.1：移除音乐律动、补齐飞行降落

基线0.8.7-electron。用户要求删除音乐律动，并处理正面飞行结束直接跳回待机的问题。本轮只维护GPT娘，保留既有角色、素材、音色、大小与用户数据。

## 移除音乐模块

删除右键与设置页的音乐入口、预加载通知接口、人物旋转/上下律动、灯效和额外灯具命中区。删除后台采集启动、数据解析、进程管理与旧显示请求入口。新版本不携带 `runtime/music-monitor.ps1`、`runtime/music-audio.cs`；命令行控制不再接受音乐开关。普通半身按压/松手音效继续使用原有实现。

监督程序的presence兼容结构保留固定 `music.enabled=false`，不再有对应采集或渲染功能。个人音效偏好和声音文件不删除，历史版本与回退备份保留原样。发布清单明确记录两项服务的安装前SHA与移除项，运行文件不会从旧基线误带回来。

## 飞行、降落与待机

“正面轻展”（`frontpose`）的结尾仍是悬浮姿态，但原路径直接回到正面待机。手动点播拖动飞行（`clip:flutter`）也存在同类缺口。现在这两条路径均为：完整飞行片段 → 现有屈膝站稳降落（`draglanding`，1.2倍速）→ 正面待机。两条片段间使用120毫秒短溶接。没有逆放飞行动作、缩放身体或新造未经认可的角色素材。

正面悬浮和降落作为同一场表演，自动待机预取降落素材，调度预留完整约11秒；任务动作反馈等它站稳后继续，任务完成卡片不受此限制。用户主动点播、抓取和取消仍能立即接管。已自行回到站姿的“轻盈舒展”（`flutterplay`）不额外补一次降落。

还修复两条实际拖动路径：起飞片段播完后保持最后悬空姿态，不再在长按期间回到站姿并丢失离地证据；已经实际离地后惯性甩出，保留松手瞬间画面随物理位置移动，停稳再降落一次。未真正呈现离地的短拖/快速松手沿用原有判定，不凭空添加降落。保持起飞准备1.2秒、66帧阈值、后段1.25倍速，以及原有重力、碰撞和甩出参数。

这次复用已有降落素材。飞行末帧与降落首帧的翼、裙形状仍有原素材差异，短溶接用于缓和；动作链完整可验证，最终原速衔接观感由用户验收。若以后需要逐姿态完全一致的专用连接，再以这两端的认可帧制作，不用长淡出掩盖问题。
