# 蓝鲸女仆桌宠维护报告 · 1.1.0

本次将审查中确认的问题修复并安装到现有桌宠。原有密钥、人设、近期记录、人物大小、参考音色均保留；没有调用收费聊天接口。

## 已完成的修复

| 项目 | 当前行为 |
| --- | --- |
| 本机控制接口 | 每次启动生成随机令牌；校验 Host 与浏览器来源；关闭仅接受认证 POST；回调接口同样鉴权 |
| 重复启动 | 固定绑定端口，并发启动只留下一个宿主；不再向其他端口启动第二份 |
| 关闭收尾 | 允许关闭后的连接重置，但必须继续确认服务已停止，避免退出成功却被误报失败 |
| 发送失败 | 输入保留为本次进程内的草稿，重新打开“对话”即可恢复 |
| 长回复截断 | 标记达到长度上限的回复，显示提示；右键提供“继续未完成的回复” |
| 清空期间旧回复回流 | 清空成功后使旧请求失效，并清除人物气泡；生成中禁止清空 |
| 记录与备份 | 默认保留上一版本；可明确勾选同时清理备份中的聊天及长期记忆 |
| 流式读取 | 不再对每个文字片段同步读取整个聊天配置；保存仍保留冲突检测 |
| 界面隔离 | 主窗口启用 Electron 沙箱；限制导航、弹窗与 IPC 来源 |
| 语音日志 | 记录固定阶段、错误码；不记录聊天原文或密钥；日志自动滚动 |
| 维护与恢复 | 定制源码、测试、安装、回退和完整离线恢复统一归档 |

## 新增使用入口

右键人物 → **设置与聊天记录**，可查看并复制最近记录、编辑长期记忆、选择清空范围。

长期记忆由你填写，可随时修改或删除后保存。它随聊天请求发送给 DeepSeek，不会自动从私人聊天中提取内容。保存配置仍保留上一版本，若要同时清理恢复副本中的内容，请使用清空页的对应选项。

发送失败后重新打开“对话”，草稿会自动填回。未发送草稿仅保留在内存中，退出桌宠后不保留。
