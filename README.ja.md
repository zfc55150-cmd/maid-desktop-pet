# 🚀 3ステップでかんたん導入＆起動ガイド（ポータブル版）

**ポータブル版（ZIP）**は [GitHub Release v1.0.11](https://github.com/zfc55150-cmd/maid-desktop-pet/releases/tag/v1.0.11) からダウンロードできます。Electron と Node.js を同梱しているため、事前の開発環境構築やインストール作業は不要です。

両マスコットは**日本語／簡体字中国語の自動判定＆手動切り替え**に対応しており、Windows のシステム言語に合わせて初回から自然な日本語 UI で動作します。また、各パッケージはフォルダ内の `state\` にデータを完全隔離しており、既存環境や2体同時起動でも干渉しません。

## 🌐 日中バイリンガル自動切り替えについて

- **初回起動時の自動判定**：OS／Electron のロケールを自動検出し、日本語版 Windows 環境では自動的に**日本語表示**（右クリックメニュー・設定パネル・吹き出し・アップデート通知など）が選択されます。
- **手動切り替え＆保存**：設定パネル（右クリックメニュー → 設定）からいつでも **`日本語` / `简体中文`** を手動で切り替えられます。選択した言語設定はパッケージ内の `state\` フォルダに保存され、次回起動時も引き継がれます。

## ステップ 2：解凍（日本語版 Windows でのポイント） / Extract

**書き込み権限のある任意のフォルダ**（例：`D:\Pets\GPTNiang` やデスクトップ上の新規フォルダ）へ**すべて展開（解凍）**してください：

- ❌ **`C:\Program Files` など管理者権限が必要なフォルダには解凍しないでください**（実行中に設定やログをパッケージ内の `state\` に書き込むため、権限不足で動作しません）。
- ❌ **ZIP ファイルを開いたまま中の `.cmd` を直接ダブルクリックしないでください**。必ずフォルダへ完全に展開してから実行してください。
- ✅ フォルダパスに日本語（全角文字）やスペースが含まれていても動作します。
- 🈶 **日本語環境 Windows での文字化け回避**：Windows 標準の解凍機能や一部の解凍ツールでは、中国語ファイル名が文字化けする場合があります。その場合でも、**同フォルダに同梱されている英数字（ASCII）版の起動・停止用 `.cmd` ファイルを使えば問題なく動作します**。

## ❓ よくある質問（FAQ）

- **Q. GPT娘は初回起動時にパソコンのどこを変更しますか？**
  - `Start-GPT-Niang.cmd` を起動すると、最初にポータブル版専用の初期化スクリプト `portable\bootstrap.cjs`（配布 ZIP にのみ同梱、ソースリポジトリには非収録）を実行し、解凍先のパスに合わせて `product.json` / `installation.json` を生成して、パッケージ内の `state\` に初期設定（表示倍率 `1.26`、ホストウィンドウ追従オフ）を書き込みます。レジストリの変更、Windows 自動起動の登録、システムフォルダへの書き込みは一切行いません。Electron のユーザーデータも `state\electron\profile` に隔離されるため、インストール版とは完全に独立しています。
- **Q. DeepSeek娘にローカル音声（TTS）機能が含まれていないのはなぜですか？**
  - 音声サブシステム一式が約 9.6 GB（Python 仮想環境 5.2 GB＋モデル重み 4.3 GB）と非常に大きく、さらに Python 仮想環境の `pyvenv.cfg` が絶対パス依存で他環境へそのまま持ち運べないため、ポータブル版では音声環境を除外しています。テキストチャット・長期記憶・アニメーションなど本体機能は問題なく利用できます。
- **Q. すでにインストール版を使っていたり、同じマスコットを2つ同時に起動しても競合しませんか？**
  - 競合しません。現行版（`v1.0.6` 以降）のポータブル版は設定・実行状態・Electron プロファイル・停止セッションのすべてを「解凍したフォルダ単位」で分離しているため、1台の PC で複数コピーを同時に動かしたり、片方だけを安全に終了したりできます。
- **Q. ポータブル版で制限されている機能はありますか？**
  - GPT娘ポータブル版では、本体アニメーション、クリック、ドラッグ、サイズ調整、セリフ吹き出し、キャラ図鑑（画像インポート）、設定パネル、およびローカルの Codex 連携／残量表示（本機に Codex が導入されている場合）がすべて利用可能です。ストア版互換レイヤーを持たないため、上流版の自己書き換え型自動アップデートと Windows スタートアップ登録は無効化されており、本リポジトリ（`zfc55150-cmd/maid-desktop-pet`）の軽量な更新通知（1日1回確認し、新バージョンがあれば通知とダウンロードページへのリンクのみを表示）のみ搭載しています。
- **Q. アンインストール（削除）するにはどうすればいいですか？**
  - 停止用 `.cmd` または右クリックメニューからマスコットを終了した後、解凍したフォルダごと削除するだけで関連するすべての設定・キャッシュ・ログを完全に消去できます。
- **Q. セキュリティソフトが警告を出す場合は？**
  - まずダウンロード元が公式の [GitHub Releases](https://github.com/zfc55150-cmd/maid-desktop-pet/releases) であること、および `SHA256SUMS.txt` のハッシュ値が一致することをご確認のうえ、セキュリティソフト側の検出理由をご確認ください。なお、DeepSeek娘で AI チャット機能を使用すると、会話内容と設定された記憶が DeepSeek API へ送信されます。

公開されている2種類のポータブル版 ZIP は、クリーンな一時作業ディレクトリで専用スクリプトによりビルドされ、出荷前に**バイナリ単位の全量スキャン**を通過しています：

- **ビルド機のユーザー名・ローカルパス非残留**：`%USERPROFILE%` に相当する個人パスは完全に除去済みです（MSVC ビルド中間ファイル `.exp` / `.obj` / `build.log` 内のパスも等長バイトでマスク済み。起動時にハッシュ検証される `native-lease.node` 本体は無改変で `build.json` と一致します）。

- `animation.json` 内に記録されていたローカルビルド機のパス 6 箇所は `<redacted-local-build-path>` へ匿名化し、`package-manifest.json` のハッシュも同期更新済みのためセルフチェックは `ok:true` となります。
