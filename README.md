## 第 2 步：解压 / Extract

解压到**任意有写权限的文件夹**，例如 `D:\Pets\GPTNiang`：

- ❌ 不要解压到 `C:\Program Files` 等需要管理员权限的目录（运行时要往包内 `state\` 写设置与日志）
- ✅ 路径含中文或空格均可
- ✅ 请**完整解压**后再运行，不要直接在压缩包内双击

## 第 3 步：双击启动 / Double-click to run

| 桌宠 | 启动 | 停止 |
|---|---|---|
| GPT娘 | `启动GPT娘 (Start GPT-Niang).cmd` | `停止GPT娘 (Stop GPT-Niang).cmd` |

## 常见问题 / FAQ

- **GPT娘首次启动做了什么？** 启动器先运行 `portable\bootstrap.cjs`，按解压位置动态生成 `product.json` / `installation.json`，并在 `state\` 写入默认设置（缩放 1.26、不跟随宿主窗口）。不写注册表、不创建开机自启、不改系统目录；Electron 用户数据也落在包内 `state\electron\profile`，与已安装版本完全隔离。
- **DeepSeek娘为什么没有语音？** 原语音子系统约 9.6 GB：Python 虚拟环境 5.2 GB 由 `pyvenv.cfg` 硬编码绝对路径、换机即失效，模型权重 4.3 GB 可重新下载。故核心包不含语音，桌宠本体功能不受影响；恢复步骤见包内 `PORTABLE-README.md` 第六节。
- **会和已安装的正式版冲突吗？** v1.0.1 的 DeepSeek 状态和端口有区分，但 Electron 配置目录与安装版共用；停止脚本在路径前缀相同时也可能误认其他副本。修复候选尚未公开。
- **便携版有哪些功能不可用？** GPT娘便携版不含应用商店兼容层，故 ChatGPT/Codex 额度显示、上游安装型自动更新、开机自启、Codex 插件注册不可用；桌宠本体（动画、点击、拖拽、缩放、气泡语录、形象图库、设置面板、自定义音效）完全正常。便携版默认开启针对本仓库（`zfc55150-cmd/maid-desktop-pet`）的轻量版本提醒（仅检查、气泡提醒一次并提供跳转下载页按钮），而上游覆盖安装器已在包内主动关闭，避免绿色版自我改写。
- **如何清除？** 停止后删除解压目录可清除其中的数据；v1.0.1 DeepSeek 的 Electron 配置另存用户目录，删除包不会自动删除它。
- **杀毒软件报毒？** 请先核对下载来源和 SHA-256，再检查安全软件给出的具体原因。聊天功能会将请求内容发送给 DeepSeek。

## 隐私保证 / Privacy guarantee

两个便携包均由构建脚本在临时目录中生成，出厂前通过**二进制级全量扫描**：

- **无本机用户名残留**：`%USERPROFILE%` 已彻底脱敏，包括 MSVC 构建中间件（`.exp` / `.obj` / `build.log`）内以**等长字节**替换的硬编码路径；启动时被校验的 `native-lease.node` 未做任何改动（哈希与 `build.json` 一致）
- **无凭据**：`sk-…`、`AKIA…`、`PRIVATE KEY`、长 `api_key` 字面量全部 0 命中
- **不含任何用户个人状态**：聊天记录、个人设置、诊断快照、运行日志、pnpm 记账注释均未打包
- `animation.json` 中 6 条指向构建机的审批/溯源绝对路径已替换为 `<redacted-local-build-path>`，`package-manifest.json` 对应条目同步刷新，故自检仍为 `ok:true`

### 分享给朋友（当前维护版）

完整包必须用 64 位 Python 生成，建议使用已安装桌宠的 `voice-runtime/python-base/python.exe`；不要使用系统中可能存在的 32 位 Python。独立解压验收入口为 `scripts/validate-share.py --archive <成品ZIP> --stage <新的work子目录>`，不会启动桌宠、调用聊天接口或修改个人数据。

`scripts/build-share.py --installed <已核对安装目录> --output <新的交付目录>` 生成完整分享 ZIP，包含当前部署代码、动画、运行环境和本地语音模型。脚本按安装根目录白名单取文件，不读取个人数据目录；排除聊天、控制令牌、缓存、日志和环境凭据文件，并逐项验证压缩后的 SHA-256。Python 环境配置去除原账户路径，安装时按接收者的位置重写。

朋友解压后双击“安装桌宠.cmd”，脚本检查文件后安装到当前账户，并创建快捷方式；已有安装时拒绝覆盖。默认关闭语音，使用空记录、通用人设和朋友自己的 Key。使用说明见 `docs/朋友分享包使用说明.txt`。打包与安装边界回归：`python -B tests/test_share_package.py`。本流程不更新本机安装，也不包含 GPT 娘的补丁。

将 `restore-offline.ps1`、完整离线 ZIP 和 `恢复包校验.json` 放在同一文件夹，运行脚本。默认目标是当前账户的标准安装目录，已有安装时拒绝覆盖。恢复会核对整个 ZIP 和每个文件，调整 Python 路径，再验证依赖；新电脑需要兼容的 NVIDIA 驱动与可用显存。本地语音不可用时仍可使用文字聊天。

新账户请自行填写 API Key。现有个人数据不会由恢复包覆盖；若需要迁移聊天，可另行备份个人数据，跨账户后重新填写密钥。

依赖导入时，第三方库可能提示可选的 SoX 或 flash-attn 未安装。本版本使用 SoundFile 与 PyTorch SDPA，固定短句播放和离线还原均已实测通过，不需要为了这些提示另行安装。

长期稳定性、蓝牙/声卡切换后的听感仍取决于实际设备。此次保留原语音生成、分句、参考音频和 400ms 尾部缓冲。
