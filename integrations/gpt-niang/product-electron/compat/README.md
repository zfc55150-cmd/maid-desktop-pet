# ChatGPT 傲娇龙娘 · Electron 正式版

人物版本：0.8.0-electron。现有额度/MCP服务协议版本单独保留，不用其版本号判断桌面人物。

双击“打开GPT娘.cmd”启动；右键人物打开菜单，“设置与功能”可查看额度、全部43动作、形态、语录、形象、声音及陪伴选项。走路是原地表演。半身保留原玻璃脸颊图片与短音效。音乐律动只读取系统音量/节拍，不保存音频。

人物使用本目录versions/0.8.0-electron中的独立Electron和Node运行时。widget.ps1仅为旧快捷方式兼容入口，没有第二套WPF人物。个人数据仍在原GPTNiangUsage/state目录。

通过已注册的用户守护任务启动；退出人物会暂停自动拉起，再次打开可恢复。任务观察和额度查询沿用原服务；既有Codex任务不会被停止。上游更新只检查和通知，不覆盖本机定制。

维护源码在女仆桌宠项目integrations/gpt-niang/product-electron。准确文件清单为版本目录package-manifest.json；诊断仅含版本、固定错误码、几何、帧标识及资源计数。屏幕画质、原速动作自然度与鼠标手感仍由用户验收。

旧人物运行文件在正式迁移验证通过后清理，回退归档单独保存在D盘GPT娘Electron正式迁移归档中；不清除个人设置、聊天或母版。
