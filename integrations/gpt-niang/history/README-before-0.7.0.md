已部署[全身 / 半身双形态](forms/README.md)：右键直接“切换形态”，共用当前位置和大小；半身复用本地语录与声音，全身保留 23 组动画。当前完整安装清单包括 forms-1.0，详见 forms/deployment.json。

2026-10-23 新增[拖动与右键交互优化](interaction/README.md)：桌面人物可部分出屏、跨屏拖动，取消跨屏幕中线自动翻面，菜单靠近鼠标并避让屏幕边缘。动作版后续构建已携带该模块。

同日菜单更新 `interaction-1.1-menu`：参照 DeepSeek 的白底紧凑菜单，首页缩为七个入口，动作与设置分层，统一所有子菜单样式。

全身人物、21 组连续动作与 Codex 状态联动的独立定制源码见 [animated/README.md](animated/README.md)。该更新另有完整预览、假数据回归和安装回退流程，正式部署状态以该次交付记录为准。

适用基线：GPT-Niang 1.3.5。此目录维护 GPT 娘的局部修复，与项目 `app/` 中的蓝鲸女仆代码分开。

独立桌面模式首次启动时，原版在 `Show()` 之前调用 `PointToScreen()`；WPF 的可视树尚未连接到 PresentationSource，会抛异常，导致挂件无法显示。补丁只在这个未连接阶段按整块画布限制坐标，显示后继续使用原版按角色边界、镜像与 DPI 计算的位置限制。

`patch-desktop-startup.cjs` 生成保留原换行的补丁文件；安装前后按 `deployment.json` 核对 SHA-256，禁止覆盖未知版本。`test-desktop-startup.ps1` 使用未显示的隔离 WPF 窗口验证 36 种启动坐标、缩放、DPI 与副屏情况；原版复现异常，补丁版通过。

部署时保留设置与代码备份，仅重启 GPT 娘。用户采用独立桌面模式、始终置顶；动作版 0.3 首次升级把人物从 80% 调至至少 140%，气泡沿用 100%，以后保留用户选择。官方自动更新可能覆盖本地修复；升级后重新核对行为与哈希，不能将此补丁强行用于新版本。

## 交互顺序补丁

`patch-interaction-order.cjs` 以已修复首次显示问题的版本为基线，增加角色按下时的一次性提升。保持桌面模式与置顶开关的含义，空闲刷新不提升窗口。DeepSeek 配套使用维护版 1.2.1，不再每 5 秒抢回顺序。

`test-layer-order.ps1` 配合 `scripts/smoke-pet-layer-order.cjs` 创建透明隔离测试窗口，使用真实 WPF 与 Electron API 验证双向提升、等待 6.5 秒后保持顺序，以及关闭置顶／回到窗口跟随时不强制提升。不会移动、最小化或关闭用户的正式窗口。
