2026-10-23 已为本机创建桌面 `GPT娘` 快捷方式，并为开始菜单 `GPT娘额度挂件 → 打开 GPT娘` 配置相同的人物图标。双击后沿用现有 `update-agent/agent-launch.vbs`，隐藏命令窗口，保留现有更新恢复与单实例启动流程。

图标由正式安装中的 `assets/gpt-dragon-niang-bust.png` 转为 16、24、32、48、64、128、256 像素 ICO，不生成新人物。`build-icon.ps1` 可重建；`gpt-niang-v1.ico` 是维护副本，实际快捷方式引用安装根目录旁的 `GPTNiangUsage/launcher/gpt-niang-v1.ico`。不放进上游管理的 `gpt-niang-usage` 子目录。

重新安装入口：`install-launcher.ps1`。默认只针对本机账户，先验证既有启动入口与图标；每次在项目 `work/gpt-niang-launcher/` 创建新的安装记录目录，备份已有快捷方式，并读回检查目标、参数、工作目录和图标。可用 `-UserRoot` 指明其他账户根目录，桌面和开始菜单位置仍按执行账户的 Windows 已知文件夹解析，因此应由目标账户运行。

本轮实际验证：新桌面快捷方式可启动既有 GPT 娘，启动前后 PID 均为 7860，状态持续刷新且可见，挂件进程数为 1。安装及试启动记录在 `work/gpt-niang-launcher/20261023-164627-559/`。DeepSeek 安装一致性、31 项语法检查、59 项假数据回归同轮通过。

仅新增图标和快捷方式，未改 GPT 娘程序、个人设置、动画、开机启动项或 DeepSeek 部署清单。原开始菜单快捷方式已备份。回退时移除新增桌面快捷方式，将记录中的 `before-2.lnk` 复制回原开始菜单位置；确认没有快捷方式引用后可移除新增图标目录。上游未来若重建开始菜单入口，可能需要重新运行本脚本恢复图标。
